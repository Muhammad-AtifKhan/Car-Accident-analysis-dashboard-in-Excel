# 🚗 Road Accident Analysis Dashboard (Power BI)

## 🔹 Overview

This project presents an interactive dashboard developed using Microsoft Power BI to analyze road accident data. It highlights key insights related to accident severity, casualties, road conditions, and environmental factors.

## 🔹 Objectives

* Analyze accident severity (Fatal, Serious, Slight)
* Identify trends in casualties over time
* Understand the impact of road type and surface
* Evaluate environmental conditions (weather & light)
* Provide insights for data-driven decision making

## 🔹 Tools & Technologies

* Power BI
* Data Visualization
* Data Cleaning & Transformation

## 🔹 Key Insights

* Majority of accidents fall under **Slight Severity (84%)**
* Highest casualties occur on **Single Carriageways**
* Most accidents happen during **Daylight conditions**
* Urban areas show higher accident rates compared to rural areas

## 🔹 Dashboard Features

* Year-wise comparison (CY vs PY)
* Monthly trend analysis
* Filter panel (Weather, Wind, Year)
* Interactive visuals for deep analysis
